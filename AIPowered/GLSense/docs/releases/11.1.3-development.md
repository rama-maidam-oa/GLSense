## When QA reports back

- **Installed side by side** (two GLSense entries in Add/Remove Programs): check the installed product's UpgradeCode against `{D4B153A7-…}`. Test machines that had an earlier AIPowered test MSI (old code `{2EED321B-…}`) need a manual uninstall first.
- **Online Reload shows nothing:**
  - Check the add-in log: session expired (401), server list empty, or "N release(s) not marked for release".
  - The history file names must be `glsenseManifests.json` / `xledgeManifests.json`, with that exact case.
- **A fix is needed:**
  - **Only `*.Addin.Core` changed:** do a DLL-only release (`DEPLOYMENT.md`). Build, then copy the new `updates/<folderName>/`. **Append** its entry to the history file and set the 11.1.3 entry's `release` to `false`. Update the `orbit-artifacts.xml` `<release_date>`. Commit with OISR + title.
  - **The shell or installer changed:** do a full release. Build a new MSI with a new ProductCode, the same UpgradeCode and a higher ProductVersion.
  - Before building, put the ticket(s) on line 1 of `ReleaseNotes.txt`.
  - Then edit the existing Jira comment with the new build commit; don't add a new comment.
- **Clean-up before the next unrelated build:** clear or replace line 1 of both `ReleaseNotes.txt` files. They still hold the 11.1.3 ticket list.
